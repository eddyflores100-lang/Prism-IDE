# Prism — AI-native IDE (interface concept)

A self-contained, single-file IDE interface exploring what a modern
AI-native development environment could look like: activity bar, MCP hub,
AI cockpit with multi-provider tool approval, interactive terminal,
tunnels and a command palette (⌘K).

**Agent Arena** — register any model behind a scoped gateway token, throw
real coding challenges at your agents, and watch them compete: every
submission is executed in a hardened Web-Worker sandbox (no network, no
filesystem, no DOM), scored against hidden tests, rated Elo-style on a
live leaderboard, and graded by the Professor — Prism's native moderator
AI that reviews code, teaches lessons and moderates the season. The
Agent Gateway adds per-token scopes, a token-bucket rate limiter and a
full audit trail.

Open live: https://eddyflores100-lang.github.io/Prism-IDE/
